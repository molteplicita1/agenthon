# API reference

Base URL `http://localhost:8000`. Interactive docs generated by FastAPI are at `/docs`.

- **Identity.** Per-person endpoints need the header `X-User-Id: <person id>`
  (`sara`, `giulia`, `marco`, `luca`).
- **Errors** come as `{"detail": "<message>"}`.

| Code | Meaning |
|---|---|
| `401` | Missing or unknown `X-User-Id`. |
| `403` | Not allowed: not the lead of the item's team, not the action's owner, source not visible. |
| `404` | Item not found, unknown track, no brief yet. |
| `409` | The item was already approved or rejected. |
| `422` | Missing `question`. |
| `503` | Gemini or ElevenLabs failed. |

## Endpoints

| Method and path | Id | Returns |
|---|---|---|
| `GET /health` | no | `{"ok": true}` |
| `GET /people` | no | `Person[]` |
| `GET /state` | yes | `{me: Person, now, thread: Message[]}`: my messages, oldest first. The bot polls it. |
| `POST /ask` | yes | Body `{"question": "…"}`. Stores the question and the answer in my thread; returns the answer `Message`. |
| `POST /memory/{id}/approve` | yes | The decided `MemoryItem`. Lead of the item's team only. |
| `POST /memory/{id}/reject` | yes | Same. |
| `POST /actions/{id}/approve` | yes | The decided `Action`. The action's owner only. Runs the effects. |
| `POST /actions/{id}/reject` | yes | Same, without effects. |
| `GET /sources/{id}` | yes | The `Source`, if visible to me. |
| `GET /brief/audio` | yes | My latest brief as `audio/mpeg`. |
| `GET /demo/overview` | no | Everything the control room shows (see below). |
| `POST /demo/next-event?track=tech` | no | `{event: Source \| null, remaining}`. Runs the next step of the demo script. |
| `POST /demo/reset` | no | `{"ok": true}`. "Start the day": fresh state from the seed, one brief per person. |

## Shapes

The TypeScript versions are in [`frontend/src/types.ts`](../frontend/src/types.ts).

**Person** `{id, name, team, is_lead, title}`; `team` is `sales`, `tech` or `finance`.

**Source** `{id, type, title, author, timestamp, body, team, visible_to}`; `type` is `email`,
`chat`, `doc`, `task` or `pr`. Tasks add `assignee`, `due_date`, `status`
(`todo`, `in_progress`, `done`). `visible_to` holds teams or `"all"`.

**Citation** `{n, source_id, type, label, quote}`. `n` matches the `[n]` marker in the text;
`label` is ready to show (e.g. `Chat · #tech · Mon 23 Nov 11:20`); `quote` may be null.

**MemoryItem** `{id, statement, team, visible_to, status, citations, created_at, decided_by,
decided_at, can_decide, caught}`. `status` is `proposed`, `approved` or `rejected`; `can_decide`
is true when the caller may approve or reject it now; `caught` lists the labels of the work this
decision caught.

**Action** `{id, title, reason, for_user, status, effects, citations, created_at, decided_at}`.
`status` is `pending`, `approved` or `rejected`. Effects:

```json
{"type": "update_task", "task_id": "task_api_migration", "changes": {"due_date": "2026-12-02"}}
{"type": "create_task", "title": "…", "assignee": "marco", "due_date": "2026-12-01"}
{"type": "send_message", "to": "#tech", "text": "…"}
```

**Message** `{id, from, kind, text, answerable, citations, actions, memory_items, created_at}`.
`from` is `user` or `brain`; `kind` is `question`, `answer`, `brief` or `alert`; `actions` and
`memory_items` hold the cards embedded in an alert. `answerable` is set on answers only.

**Overview** (`GET /demo/overview`)

```text
{
  now,                  fictional clock
  tasks: Source[],      the task board
  outbox: [{id, to, text, sent_at, action_id}],   the simulated sent messages
  memory: MemoryItem[], all items, with can_decide false
  last_event: Source | null,
  remaining_events: {tech: n, finance: n},
  next_step: {tech: "…" | null, finance: "…" | null}   what the next press will send
}
```

## Examples

`-X` sets the method, `-H` adds a header, `-d` sends the JSON body.

```bash
curl -X POST localhost:8000/demo/reset
```

```bash
curl -X POST localhost:8000/ask -H 'X-User-Id: luca' -H 'Content-Type: application/json' -d '{"question":"What is the Alpilog contract value?"}'
```

```bash
curl -X POST 'localhost:8000/demo/next-event?track=tech'
```

```bash
curl -X POST localhost:8000/actions/act_golive/approve -H 'X-User-Id: giulia'
```
